# 🛒 Online Shopping Management System

## About the Project

A SQL-based DBMS project to manage customer information and orders using MySQL.

## Features

* Create Customer and Orders tables with appropriate constraints.
* Insert, update, and delete records.
* Retrieve orders above ₹5,000.
* Calculate customer-wise totals using GROUP BY and SUM().
* Filter grouped results using HAVING.
* Calculate average order amounts using AVG().
* Modify table structures using ALTER TABLE.

## Database Tables

* Customer: Stores customer ID, name, email, city, and age.
* Orders: Stores order ID, customer ID, order date, amount, status, and payment method.

## Technologies Used

* MySQL
* SQL
* RDBMS

## How to Run

1. Open `online_shopping_management.sql` in MySQL Workbench.
2. Execute the script.
3. Review the query results.

Note: The script recreates the `OnlineShopping` database. Back up existing data before running it.
